# Глоссарий и правила русского интерфейса ConstructCraft

Единый источник терминов для всех частей перевода. Термин из таблицы переводится только так, как в
таблице, во всех строках (кнопка, подсказка, сообщение, имя по умолчанию). Нет термина в таблице —
выбрать общепринятый в российском проектировании (СПДС, ГОСТ 21.xxx, СП) и выписать в отчёт
(`REPORT.md`, раздел «Новые термины»): ревьюер сведёт их между частями.

## Clean-room (условие автора программы, CONTRIBUTING.md)

- Не копировать тексты, фразы и строки из локализаций платных программ (Revit, ArchiCAD, Renga,
  nanoCAD, AutoCAD и др.) и их справки. Переводить с английского (`en.ftl`) своими словами; смысл
  при сомнении сверять с португальским оригиналом (`pt-BR.ftl` — эталонный язык проекта) и с кодом,
  где используется ключ (`git grep -n '"<ключ>"' crates`).
- Отдельные общие строительные термины (стена, перекрытие, разрез, фасад, спецификация, лист) — общая
  лексика отрасли и норм, их использовать можно и нужно.

## Стиль

- Регистр как в русском интерфейсе: с заглавной только первое слово и имена собственные
  («Сведения о проекте», не «Сведения О Проекте»). Английский Title Case не переносить.
- Команды, кнопки, пункты меню — глагол в инфинитиве: «Сохранить», «Создать стену», «Удалить вид».
  Названия окон, вкладок, групп, полей — существительное: «Свойства», «Параметры типа».
- Подсказки и описания — полные предложения, нейтрально или на «вы» со строчной буквы
  («Щёлкните две точки…», «Выберите стены…»). Сообщения о результате — прошедшее время, без
  восклицаний: «Проект сохранён.», «Создано стен: { $count }.»
- Буква «ё» пишется везде, где она есть (объём, конёк, подступёнок, ещё, всё).
- Кавычки «ёлочки». Многоточие «…» и знаки `→`, `·`, `×`, `‹ ›` — как в исходнике.
- Множественного числа в формате нет (одна строка на ключ). Фразы с числами строить так, чтобы
  число не требовало согласования: «Шагов: { $count }», «{ $count } шт.», «Создано элементов:
  { $count }». Не писать «{ $count } элементов».
- Подстановки `{ $имя }` — без изменений (пробелы внутри скобок обязательны), порядок в фразе можно
  менять. Текст в обратных кавычках, `%ключ%`, имена команд и параметров Lua/JSON (`wall_create`,
  `type_set`, `ccad.run`), пути, расширения (`.ccad`, `.ccomp`), горячие клавиши (`Ctrl+Z`) — не
  переводить.
- Названия форматов и программ не переводить: IFC, PDF, SVG, DXF, DWG, CSV, glTF, OBJ, PNG,
  SketchUp, Revit, Lua, MCP, Draco, ConstructCraft.
- Единицы — русскими сокращениями: м, см, мм, м², м³, л, кг, кН, МПа, °, %; британские: фут, дюйм,
  ярд, галлон (США). «{ $run } m» → «{ $run } м». Десятичный разделитель в текстах и именах по
  умолчанию — запятая («Текст 3,5 мм», «Лестница 1,00 м»); знак размера «150x100» — как в исходнике.
- Длина: короткие надписи (лента, кнопки, вкладки, заголовки столбцов, грани видового куба) — не
  длиннее английских больше чем на треть, иначе они обрежутся. Если не помещается — короче синоним
  или общепринятое сокращение с точкой («Смещ. сверху» — только если иначе никак).
- Строки ровно одна на ключ: без переносов строки, без `=` в начале значения.
